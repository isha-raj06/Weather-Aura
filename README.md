# Weather-Aura
Weather Aura — a modern, responsive weather application that delivers real-time weather conditions, forecasts, and detailed atmospheric information through a clean and engaging interface.

## ✨ Features

- 🌡️ Real-time temperature
- 📍 Location-based weather
- 💨 Wind speed
- 💧 Humidity
- 🌦️ Weather forecasts

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Weather API
